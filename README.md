## 📌 Overview
Welcome to the **Modern Swing Calculator App**! This is a desktop GUI application designed to deliver a smooth and native calculator experience. Built entirely using Java, it combines a modern dark-mode aesthetic with powerful mathematical evaluation logic, making it both visually appealing and highly functional.

---

## 🚀 Key Highlights & UI Design

| Component / Feature | Description |
| :--- | :--- |
| 🌙 **Dark Theme UI** | Styled with a custom dark palette (`#1E1E1E`) and high-contrast text for a comfortable viewing experience. |
| 🎨 **Color-Coded Buttons** | • **Green (`=`):** Execute actions<br>• **Red (`CE`, `DEL`):** Clear & delete utilities<br>• **Blue (`x²`, `√`, Operators):** Math functions |
| 🛡️ **Smart Validation** | Prevents crashes with built-in error handling for division by zero and invalid square roots (displays `"Invalid"` gracefully). |
| 🔄 **Advanced Features** | Supports parentheses `()`, negative sign toggling `(-)`, and custom expression parsing. |

---

## 🛠️ Tech Stack

* **Language:** Java
* **UI Libraries:** Swing, AWT (`JFrame`, `JPanel`, `JButton`, `JTextField`)
* **Architecture:** Event-Driven Programming with Custom Recursive Descent Parser
* **Development Environment:** Visual Studio Code / Terminal
